# Текущее состояние экранов

Свежие кадры с дев-сборки, окно 896×414 — пропорции телефона в ландшафте.
Это то, как игра выглядит **сейчас**; папка `../shots-redesign/` — история
промежуточных шагов, для оценки текущего вида её смотреть не нужно.

## Что изменилось с прошлого набора кадров

- **Поле 12×6 вместо 16×8.** 128 фишек на телефоне давали слишком мелкую цель
  для пальца: клетка выходила около 40×36 при ширине сцены 720. Сейчас 72 фишки
  и клетка 56×49.
- **Зазор между плитками уменьшен.** В `tile-base.svg` плитка нарисована как
  `rect x=6 width=88` при `viewBox 100`, то есть по 6% пустого поля с каждой
  стороны под тень. При размере клетки это читалось как лишний отступ. Подложка
  растянута до 108%, плитка занимает ~95% клетки.
- **Фон вынесен из сцены.** Сцена жёстко 720×405 и вписывается в экран с полями,
  поэтому фон внутри неё накрывал только сцену, а по краям оставалась заливка.
  Теперь это фиксированный слой на весь вьюпорт.
- **Подписи кнопок влезли внутрь таблетки.** Ширину задавал инлайновый стиль из
  пропа со значением по умолчанию 150 и перебивал CSS; у таблетки `rx=40` при
  высоте 80, торцы полностью круглые, и текст без горизонтального отступа
  заезжал на скругление.
- **Звук и музыку можно выключить прямо в игре**, не только в меню. Тумблеры
  переехали в общий компонент `AudioToggles.vue` — он же теперь в меню.

## Что из набора ассетов осталось неиспользованным

- `plus-score.svg` — в нём нарисованы собственные «+» и «P», и число поверх них
  накладывается на чужие глифы. Подложка плашки очков сделана стилями в палитре
  ассета. Нужна версия без глифов, только рамка.
- `hud-panel.svg` — у ассета фиксированные пропорции 720×76, а SVG в
  `background-size: 100% 100%` не растягивается: `preserveAspectRatio` по
  умолчанию вписывает его с полями, панель рисовалась заметно уже шапки и
  обрезала крайние иконки. Заменён CSS-эквивалентом в тех же цветах. Чтобы
  использовать сам файл, ему нужен `preserveAspectRatio="none"`, но тогда
  поплывут скругления.
- `logo-leaf.svg` — логотип уже с листьями, добавка читалась бы лишней деталью.

## Чего в игре по-прежнему нет

Подсказки на поиск пары, паузы, обучения в режиме Group. Интерфейс только
английский: `vue-i18n` подключён, словарь пустой. Иконки подсказки в наборе нет.
