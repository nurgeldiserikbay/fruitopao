## Приёмка по критериям handoff

| Критерий | Факт |
|---|---|
| Сетка 12×6, механика не менялась | 72 плитки, правила и баланс не тронуты |
| Плитки заметно цветные | все 72 имеют градиент, цвет по `type % 4` |
| HUD из капсул | Back, Level, Timer, Shuffle, Score — отдельные капсулы |
| HUD в зоне y 10–62 | замерено ровно 10–62 |
| Поле в зоне y 62–347, максимум 580×285 | замерено 62–347, размер 580×285, клетка 48×48 |
| Нижние 53 px свободны | свободно 58 px, поле заканчивается на y=347 |
| Меню помещается в 640×300 | три кнопки и Privacy Policy видны при обоих размерах |
| Production build проходит | `pnpm build:prod` без ошибок |
| Эталоны валидны | оба PNG проверены: IEND на месте, CRC сходится, IDAT распаковывается |

## Вес шапки

Первый вариант капсул вышел тяжёлым: все пять были высотой 44 px, а полоса
времени тянулась на всю высоту капсулы и на половину ширины шапки. Из пяти
капсул нажимаются только две — «назад» и перемешивание, — поэтому высота
кнопки остальным не нужна. Сейчас:

| Элемент | Размер | Нажимается |
|---|---:|---|
| Назад | 40×43 | да |
| Музыка / звук | 34×34 | да |
| Перемешать | 72×38 | да |
| Уровень | 90×38 | нет |
| Таймер | 230×38 | нет |
| Счёт | 70×38 | нет |
| Полоса времени внутри капсулы | 167×10 | нет |

Тумблеры звука при этом наоборот подросли с 26 до 34 px: 26 мало для пальца,
а сама иконка внутри осталась прежней.

## Отступления и незакрытое

- **`+score` не летит к капсуле Score.** Сейчас число всплывает над снятой
  парой и затухает. Полёт к счётчику требует пересчёта координат между слоем
  эффектов внутри поля и капсулой в HUD — это разные системы координат.
- **Анимация тапа (scale 1 → .94 → 1) не сделана.** У фишки занят `transform`:
  инлайновый стиль раскладывает сетку, GSAP пишет туда же на анимации маршрута.
  Отдельное свойство `scale` не спасает — оно применяется после `transform` и
  домножает позицию в сетке, разбросав фишки. Масштаб доступен только через
  `background-size` фрукта, а это не то же самое, что нажатие всей плитки.
- **Реальный adaptive banner на устройстве не проверен** — нет доступа к
  Android-сборке на железе. Геометрия под него выдержана: ниже y=347 игрового
  UI нет.
- **`hud-panel.svg` и `tile-base.svg` из набора v1 больше не используются**:
  их заменили капсулы и цветные плитки v2. `plus-score.svg` и `logo-leaf.svg`
  не используются с самого начала — в первом нарисованы собственные глифы,
  второй дублирует листья, уже имеющиеся в логотипе.
