# Fruito Pao — UI assets handoff

Этот набор предназначен для полного визуального обновления без изменения рекламы,
Android-обвязки и игровой логики. WebP созданы как стилевые, фоновые и игровые
ассеты, SVG — как готовые масштабируемые элементы интерфейса.

## Главное изменение архитектуры плитки

Старые `public/img/fruits/*.png` содержат фрукт и сиреневую плитку в одном растре.
Их нельзя качественно перекрашивать или анимировать независимо. Новая плитка должна
состоять из трёх слоёв:

1. `tile-base.svg` или его CSS-эквивалент как фон;
2. прозрачный `public/img/fruits-redesign/{id}.webp`;
3. оверлей состояния (`tile-selected.svg`, `tile-group-selected.svg`, match/error).

Старую папку пока не удалять: сначала переключить пути во всех режимах и проверить
сборку. После подтверждения старые PNG можно удалить отдельным коммитом.

Рекомендуемый размер фрукта внутри клетки: `82–86%`. Плитка не должна получать
случайный цвет по ID — одинаковая нейтральная основа ускоряет поиск совпадающих форм.
Различимость создают силуэт фрукта и явные состояния выбора.

## Правила композиции экранов

### Start

- Использовать `menu-tropical.webp` с `background-size: cover`.
- Логотип оставить текущий, но ограничить шириной около `280px` в сцене 720×405.
- Три кнопки режимов расположить одной вертикальной группой с расстоянием `10px`.
- Music/Sound оставить в верхнем левом углу; Privacy Policy — в safe-area снизу.

### Classic

- Использовать `game-calm.webp`.
- Под сеткой добавить единую полупрозрачную плашку `rgba(54, 55, 105, .16)` с радиусом `14px` и внутренним отступом `4px`.
- Заменить запечённые старые PNG на композицию `tile-base.svg` + новый прозрачный WebP.
- Выбранную фишку поднять над соседями через `z-index`, масштабировать до `1.08` и показать `tile-selected.svg` поверх неё.
- В HUD показать `LEVEL N`; номер нельзя прятать только в итоговом экране.

### Time

- Базовая композиция совпадает с Classic.
- Рядом с таймером/в правой части HUD показывать `time-seed-ring.svg` как отдельный отсчёт подсева.
- За 1.5 секунды до подсева пустые клетки кратко подсветить мягким коралловым контуром, чтобы новые фишки не выглядели случайной помехой.

### Group

- Целевой фрукт оставить в HUD и окружить `group-target-ring.svg`.
- Уже выбранные фрукты показывать через `tile-group-selected.svg`; не снижать opacity содержимого.
- Добавить счётчик `selected / total` возле цели, чтобы правило режима читалось без длинного обучения.

### Result

- Использовать `menu-tropical.webp` с затемняющим слоем `rgba(28, 54, 91, .16)`.
- Карточка результата: заголовок, итоговый счёт, лучший счёт при наличии, `Next` после победы и `Home` при проигрыше.
- Не менять момент показа interstitial: он остаётся только на экране пройденного уровня согласно `AGENTS.md`.

## Анимации и микроанимации

| Событие | Анимация | Длительность |
|---|---|---:|
| Нажатие фишки | `scale 1 → .94 → 1.08`, появление рамки, лёгкий подъём тени | 160 мс |
| Смена выбора | Старая рамка `opacity 1 → 0`, новая `0 → 1`; без мигания всей сетки | 120 мс |
| Верная пара | Маршрут GSAP как сейчас; у конечной фишки 4–6 `sparkle.svg`, затем обе фишки `scale → .65`, `opacity → 0` | 260–340 мс после маршрута |
| Очки | `+20` поверх `plus-score.svg`: подъём на 22px и исчезновение | 520 мс |
| Неверная пара | Два коротких горизонтальных сдвига на 3px, коралловый контур | 180 мс |
| Shuffle | Волна по строкам: `scale .92 → 1` с шагом 18 мс; блокировать повторный тап до завершения | 300–420 мс |
| Time: ожидание подсева | Кольцо равномерно уменьшается; последние 1.5 с — один мягкий pulse | по интервалу |
| Time: появление пары | `scale .7 → 1.06 → 1`, opacity `0 → 1`, задержка второй фишки 45 мс | 240 мс |
| Group: верный фрукт | Янтарная рамка рисуется по периметру, цель в HUD делает один `scale 1 → 1.08 → 1` | 190 мс |
| Group: чужой фрукт | Набранные рамки быстро уходят каскадом, HUD-цель делает shake 3px | 220 мс |
| Победа | 10–14 переиспользуемых sparkles по краям карточки; без конфетти на всё поле | 700 мс |

Все анимации должны иметь fallback для `prefers-reduced-motion: reduce`: оставить только
смену opacity до 100 мс, без scale, shake и каскадов. Не анимировать `filter: blur()` и
крупные тени — это дороже на слабых Android-устройствах; использовать `transform` и `opacity`.

## Технические замечания

- WebP имеют точный размер 1280×720; использовать `cover`, не растягивать по двум осям.
- SVG не содержат текста и нормально масштабируются вместе с фиксированной сценой 720×405.
- Все 30 фруктов имеют размер 144×144, прозрачные углы и общий вес менее 200 КБ.
- Не загружать одновременно старый и новый набор: после переключения пути браузер должен запрашивать только `fruits-redesign`.
- Для рамок установить `pointer-events: none` и `position: absolute; inset: -5%`.
- Не править `docs/` вручную. Claude после интеграции должен выполнить `pnpm build:prod`, чтобы обновить опубликованный билд.

## Промты использованных WebP

Изображения сгенерированы встроенным ImageGen.

- `menu-tropical.webp`: светлый тропический 16:9 фон с водой, листьями и спокойной центральной зоной; без текста, UI и персонажей.
- `game-calm.webp`: минимальный низкоконтрастный aqua-фон с едва заметной текстурой и листьями только по крайним углам; без объектов в центре.
- `gameplay-direction.webp`: high-fidelity референс Onet Connect с сеткой 16×8, компактным HUD и явно выделенной фишкой.
