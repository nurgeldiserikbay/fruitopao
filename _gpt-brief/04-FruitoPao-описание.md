# Fruito Pao — описание игры

Мобильная головоломка «соедини пару» (жанр Onet Connect / Mahjong Connect) на фруктах.
Android, Google Play, `com.thelightcome.fruitopao`, версия 6.0 (versionCode 6).
Только ландшафтная ориентация, полноэкранный режим.

К этому файлу приложены 8 скриншотов из папки `shots/` — они сняты с реальной сборки,
разрешение 1280×720.

---

## 1. Суть игры

Поле 16×8 = **128 фишек**, каждая — один из **30 видов фруктов**. Фишки лежат парами
(64 пары, виды выбираются случайно, один вид может встретиться несколько раз).

Игрок тапает две **одинаковые** фишки. Пара исчезает, если между ними существует путь
по пустым клеткам **не более чем с двумя поворотами** (классическое правило Onet;
путь может выходить за границу поля — вокруг доски есть невидимая пустая рамка).
Найденный путь проигрывается анимацией: первая фишка «едет» по маршруту ко второй.

Цель уровня — убрать всё поле до истечения таймера.

### Очки

- +20 за каждую снятую пару;
- при победе к счёту добавляется **весь остаток таймера** (то есть скорость = очки);
- счёт накапливается через уровни и обнуляется только при выходе в меню.

### Таймер

Полоса вверху экрана. Тик — 100 мс, запас на уровень падает с ростом уровня:

| Уровень | Запас |
|---|---|
| 1 | 800 с |
| 2 | 760 с |
| 3 | 720 с |
| … | −40 с за уровень |
| 9+ | 480 с |

В режиме Group весь запас делится на 4 (то есть 200 с на первом уровне).

### Перемешивание

Счётчик перемешиваний — **5 зарядов** (иконка со стрелками в HUD, +1 заряд за каждый
пройденный уровень, но не больше 5).

- Кнопку можно нажать вручную в любой момент.
- Игра сама перемешивает поле, если ходов не осталось, и списывает за это заряд.
- Если ходов нет, а зарядов не осталось — **уровень проигран**.

### Гравитация уровней

После каждого снятия пары поле «схлопывается» по одному из 9 шаблонов, номер шаблона =
`уровень % 10`. На уровнях 0, 10, 20… поле статично, дальше по кругу: сдвиг ряда вправо,
влево, столбца вверх, вниз, разбег от центра, схлопывание к центру и комбинации.
Это главный источник роста сложности: расклад после каждого хода меняется.

## 2. Экраны и режимы

### Главное меню (`01-start-menu.png`)

Логотип, три кнопки режимов, переключатели музыки и звука в левом верхнем углу,
ссылка на Privacy Policy внизу. Больше ничего: ни настроек, ни рекордов, ни туториала.

### Classic (`02-classic-board.png`, `03-classic-selected.png`, `04-classic-progress.png`)

Базовый режим. Поле не пополняется, убрал всё — уровень пройден, появляется кнопка **Next**.

HUD сверху: кнопка «назад», полоса таймера, счётчик перемешиваний, счёт со звёздочкой.
Номер уровня на экране **не показывается**.

Выделенная фишка подсвечивается очень слабо — `opacity: 0.8` плюс полупрозрачная
салатовая заливка `#bff75f75`. На скриншоте `03` выбранное яблоко в 3-м ряду
почти не отличается от соседних.

### Time (`05-time-board.png`)

То же поле и те же правила, но **пустые клетки периодически заполняются новыми парами**.
Интервал подсева: `max(5000, 35000 / ∛(число пустых клеток + 2))` мс — чем сильнее
расчищено поле, тем чаще подсев. Визуально режим неотличим от Classic: никакого
индикатора «сейчас будет подсев» нет.

### Group (`06-group-board.png`, `07-group-selected.png`)

Другая механика. В HUD (справа, вместо счётчика перемешиваний) показан **фрукт-цель**.
Нужно натапать **все** фишки этого вида на поле — тогда они снимаются разом.
Тап по чужому фрукту сбрасывает уже набранное выделение. Таймер идёт вчетверо быстрее.

Проблема та же: выделенные фишки на `07` (киви) отличаются от невыделенных только
прозрачностью — их приходится искать глазами.

### Итог (`08-result-score.png`)

Экран «Your Score» с итоговым счётом и одной кнопкой — домой. Показывается при
проигрыше (кончилось время или ходы). Рекорд нигде не сохраняется и не показывается.

## 3. Технический стек

| | |
|---|---|
| Фреймворк | Vue 3 (Composition API, `<script setup>`) + TypeScript |
| Сборка | Vite 5, выход в `docs/` |
| Состояние | Pinia (`pageStore` — роутинг между 4 экранами, `adsStore`) |
| Анимация | GSAP (timeline для движения фишки по маршруту) |
| Стили | SCSS, scoped |
| Обёртка | Capacitor 8 (Android + iOS-конфиг), плагины: admob, preferences, screen-orientation, splash-screen, status-bar, fullscreen |
| Шрифт | Luckiest Guy (один на весь интерфейс) |
| Звук | 8 mp3: клик, выбор, ошибка, снятие, перемешивание, конец времени, музыка меню, музыка игры |

Роутера нет — экран переключается подстановкой компонента через Pinia-стор.
Всё поле рендерится абсолютно спозиционированными `div`-ами с `background-image`
(`transform: translate(col*100%, row*100%)`), масштаб сцены — фиксированные
720×405, вписанные в экран через `scale()`.

`vue-i18n` подключён, но словарь пустой (`langs/en.ts` = `{}`) — **все надписи
захардкожены по-английски**.

`pinia-plugin-persistedstate` установлен, но **ни один стор не персистится** —
прогресс, рекорды и настройки звука не переживают перезапуск.

### Реклама

- Баннер снизу — на входе в любой режим, снимается на выходе.
- Interstitial — **только на экране пройденного уровня**, не на кнопке перехода
  (чтобы реклама не задерживала старт следующего уровня — это нарушение правил Google).
- Минимальный интервал между межстраничными — 60 с.
- Детские флаги включены: `tagForChildDirectedTreatment: true`,
  `maxAdContentRating: General`, `npa: true` в каждом запросе.

## 4. Визуальное состояние

- Фон: голубой градиент `#7ef6ff → #3ae5ff` плюс повторяющаяся текстура с фруктами
  и пузырями. Одинаковый на всех экранах, включая игровое поле.
- Фишки: приглушённо-сиреневые плитки с рисованными фруктами, лёгкая тень.
- Кнопки: красные «конфетные» с бликом.
- HUD: полупрозрачная белая плашка с `backdrop-filter: blur(3px)`.
- Всё в одном стиле, но фон под полем и сами фишки конкурируют за внимание:
  насыщенный узорчатый фон просвечивает вокруг доски и в снятых клетках.

## 5. Что в игре отсутствует

Список сознательно фактический — это то, чего в коде нет:

- нет подсказки (hint) на поиск пары;
- нет паузы; кнопка «назад» выходит в меню сразу, без подтверждения и без сохранения;
- нет номера уровня в HUD;
- нет рекордов, статистики, прогресса между сессиями;
- нет переключателей музыки/звука внутри игры — только в меню;
- нет обучения и объяснения правил (особенно заметно в Group);
- нет комбо/серий, ежедневных заданий, наград, любой мета-прогрессии;
- нет локализации (только английский, интерфейс из 5 слов);
- обратной связи за верный ход почти нет: звук + исчезновение, без частиц и всплывающих очков.
